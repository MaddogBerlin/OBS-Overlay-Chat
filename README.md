# Browser Chat v1.0

Ein modernes Browser-Overlay für **Streamer.bot** und **OBS Studio**, das Twitch-Chatnachrichten und Twitch-Events in Echtzeit als stilvolles Chat-Overlay darstellt.

Browser Chat wurde entwickelt, um Streamern eine übersichtliche, moderne und leicht anpassbare BrowserSource für OBS bereitzustellen. Alle wichtigen Twitch-Ereignisse werden über eine zentrale Streamer.bot-Action verarbeitet und direkt als Overlay angezeigt.

## Funktionen

- 💬 Live Twitch Chat
- 💚 Follow Events
- ⭐ Subscription Events
- 🔄 Resubscription Events
- 🎁 Gift Subscription Events
- 💜 Cheer / Bits Events
- 🎨 Individuelle Eventfarben
- 🖼 Plattform-Icons
- 📄 Integrierter Event-Logger
- ⚡ Zentrale Streamer.bot Main Event Action
- 🛠 HTML / CSS / JavaScript basiertes Browser-Overlay
- 📦 Einfache Anpassung und Erweiterung

## About
- 💬
Browser Chat entstand aus dem Wunsch, ein modernes, leicht verständliches und vollständig lokales Chat-Overlay für Streamer.bot und OBS Studio zu entwickeln.

Das Projekt wird als Freizeitprojekt entwickelt und kostenlos mit der Community geteilt.

Es werden keine Daten an externe Server übertragen, keine Telemetrie verwendet und keine persönlichen Daten gesammelt. Alle Dateien und Ereignisse verbleiben auf dem lokalen Computer.

Viel Spaß beim Streamen!
