# Browser Chat Settings – Vorschau v1.4

Diese Seite zeigt die Oberfläche und die wichtigsten Einstellungsbereiche
des Browser Chat Settings Tablets in Version 1.4.

Die Einstellungen können direkt in der Vorschau getestet und anschließend
lokal gespeichert werden.

---

## 🔴 Start / Power

![Browser Chat Settings – Start](screenshots/Tablet_v1-4GIFn.gif)

Über den Power-Button wird das Browser Chat Settings Tablet geöffnet.
Der animierte Startbildschirm bildet den Einstieg in die Einstellungen.

---

## ⚙️ Hauptansicht

![Browser Chat Settings – Hauptansicht](screenshots/Tabletv1-4.png)

Die Hauptansicht dient als zentrale Übersicht des Settings Tablets.

Über das mittlere Menü stehen die vier Bereiche zur Verfügung:

- Channel Chat Settings
- Animation Settings
- Live Chat Settings
- Tablet Settings

Auf der rechten Seite befindet sich die gemeinsame Chat-Vorschau,
in der Änderungen direkt betrachtet werden können.

---

## ✨ Animation Settings

![Browser Chat Settings – Animation Settings](screenshots/Tabletv1-4-Animation-Settings.png)

Im Bereich **Animation Settings** wird festgelegt, wie neue Chat-Nachrichten
in der Vorschau erscheinen.

Zur Verfügung stehen verschiedene Animationen sowie Einstellungen für
Einblendgeschwindigkeit und Darstellungsdauer.

Die Preview Controls verändern ausschließlich die Vorschau und überschreiben
nicht die ursprünglichen Animationseinstellungen.

---

## 💬 Channel Chat Settings

![Browser Chat Settings – Channel Chat Settings](screenshots/Tabletv1-4-Channel-Chat-Setting.png)

Die **Channel Chat Settings** enthalten die individuellen Einstellungen
für Twitch, Kick und YouTube.

Hier können unter anderem angepasst werden:

- Fensterbreite
- Plattform
- Chat-Design
- Hintergrundfarbe
- Textfarbe
- Schriftart
- Emotes & Filter

Die gemeinsame Vorschau zeigt direkt, wie Nachrichten der verschiedenen
Plattformen im Browser Chat dargestellt werden.

---

## 📡 Live Chat Settings

![Browser Chat Settings – Live Chat Settings](screenshots/Tabletv1-4-Live-Chat-Setting.png)

Die **Live Chat Settings** zeigen den tatsächlichen Live-Chat für das
OBS-Browser-Overlay.

Hier kann unter anderem die Darstellungsdauer der Nachrichten angepasst werden.

Der dunkle Hintergrund dient ausschließlich der Darstellung innerhalb
des Settings Tablets. Im OBS-Overlay bleibt der Live Chat transparent.

---

## 🎨 Tablet Settings

![Browser Chat Settings – Tablet Settings](screenshots/Tabletv1-4-Tablet-Chat-Setting.png)

Die **Tablet Settings** verändern ausschließlich das Erscheinungsbild
des Settings Tablets und haben keinen Einfluss auf das Chat-Overlay.

Zur Verfügung stehen verschiedene Farbmodi sowie Einstellungen für
Button- und Rahmenfarben.

---

## 🩶 Harmony Theme

![Browser Chat Settings – Harmony Theme](screenshots/Tabletv1-4-Theme-Harmony.png)

**Harmony** ist eines der integrierten Designs für das Settings Tablet.

Das Theme kombiniert einen geteilten rot-silbernen Rahmen mit hellen,
frostähnlichen Buttons und einem passend abgestimmten Power-Button.

---

## 🔴 Power / Schließen

![Browser Chat Settings – Power](screenshots/Tablet_v1-4GIFn.gif)

Über den Power-Button kann das Settings Tablet wieder geschlossen werden.

Die Einstellungen bleiben dabei entsprechend des zuvor verwendeten
Speichervorgangs erhalten.
